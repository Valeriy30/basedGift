# 🚀 Быстрый старт с CDP

## 1️⃣ Получите CDP API Key
1. Зайдите на https://portal.cdp.coinbase.com/projects/api-keys
2. Создайте новый проект "basedGift"
3. Скопируйте API Key

## 2️⃣ Настройте переменные окружения
```bash
# Откройте .env и добавьте:
VITE_CDP_API_KEY=your_cdp_api_key_here
```

## 3️⃣ Запустите проект
```bash
npm install  # Уже установлено @coinbase/onchainkit
npm run dev
```

## ✨ Что теперь работает?

### 1. Стабильный RPC без ошибок 429
- CDP RPC используется в приоритете
- Alchemy - резервный fallback
- Автоматическое переключение

### 2. Smart Wallet с Passkeys
- Кликните "Connect Wallet" в навбаре
- Выберите "Coinbase Smart Wallet"
- Создайте кошелек через FaceID/TouchID

### 3. Бесплатный газ для пользователей
- Транзакции спонсируются через CDP Paymaster
- Пользователям не нужен ETH для газа

### 4. NFT изображения не битые
- Автоматический fallback между IPFS шлюзами
- nftstorage.link → dweb.link → ipfs.io

### 5. Оптимизированная производительность
- Меньше запросов к RPC (polling 12 секунд)
- Кэширование 5 минут (нет спама при переключении вкладок)

### 6. Покупка USDC в приложении
- Введите сумму больше баланса
- Появится кнопка "Buy USDC"
- Оплата картой/Apple Pay/Google Pay

### Тест 4: IPFS Images
1. Перейдите в "Create Gift"
2. Выберите "NFT"
3. Изображения должны загружаться

1. В "Create Gift" выберите USDC
2. Введите сумму > вашего баланса
3. Кликните "Buy USDC"

## ⚠️ Важно

- **Paymaster** может требовать whitelist контракта для mainnet
- **Onramp** доступен не во всех странах
- **React 18** работает с OnchainKit через `--legacy-peer-deps`

## 🆘 Помощь

### Ошибка: "Rate Limited"
- Проверьте `VITE_CDP_API_KEY` в .env
- CDP RPC должен использоваться первым

### Ошибка: "Paymaster not configured"
- Для testnet должно работать из коробки
- Для mainnet - whitelist контракт в CDP Portal

### Изображения NFT не загружаются
- Проверьте консоль на CORS ошибки
- Некоторые NFT могут иметь невалидные IPFS ссылки

### Onramp не открывается
- Проверьте, что `VITE_CDP_API_KEY` установлен
- Проверьте, что ваша страна поддерживается
